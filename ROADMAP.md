# DOGCRUSH — Development Roadmap

## Versión 0.1 — Prototipo Jugable (ACTUAL) 🎯
- [x] Estructura del proyecto Unity 6.5.
- [x] Configuración de Git e integración con GitHub.
- [x] Generación automática de tablero (7x9) y 5 tipos de fichas.
- [x] Mecánica de selección por arrastre (ratón y pantalla táctil).
- [x] Reglas de adyacencia, no duplicados y retroceso/deshacer.
- [x] Animaciones de caída por gravedad y reposición de fichas.
- [x] Sistema de puntuación, combos y racha temporal.
- [x] Bucle de partida contrarreloj de 60s con Game Over y botón reiniciar.
- [x] Guardado de récord local mediante PlayerPrefs.

---

## Versión 0.2 — Arte, Audio y Game Feel 🎨
- [ ] Ilustraciones 2D profesionales para las fichas y fondo.
- [ ] Efectos de partículas de destellos al eliminar fichas.
- [ ] Banda sonora alegre y efectos de sonido (ladridos suaves, pops).
- [ ] Feedback háptico (vibración) en dispositivos móviles.

## Versión 0.3 — Modos de Juego y Niveles 🗺️
